# StockAssistant-Jupiter

Proyecto base para un asistente de stock y supply chain con Python, FastAPI, PostgreSQL y Jupyter.

## Estructura

- `src/`: código fuente del proyecto
- `docker/`: infraestructura con PostgreSQL y pgAdmin
- `data/`: datos crudos, generados y procesados
- `notebooks/`: análisis exploratorio
- `tests/`: pruebas automatizadas

## Comandos rápidos

- `make build`
- `make up`
- `make generate`
- `make load`
- `make api`
